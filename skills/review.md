# review · 系统复习

## 适用

用户要求复习或系统学习课程、章节或主题，需要组织知识关系、衔接学习位置，或回顾已经学过的内容。这里的复习可以包含讲解与可选练习，不能默认等同于考试。

## 不适用

简单定义或只要结果时直接回答；单个概念的深入理解使用 concept；明确要考考我、直接练习或下一题时使用 exam。

## 步骤

1. 确认当前范围。优先使用用户点名的课程、章节、已选资料和有效历史；已给定目标、基础、时间或不想练习时直接应用，不重复询问。用户只说“复习”且无法确定学科时，只问一个范围问题。
2. 建立有依据的小范围。存在相关资料时，先用 search_context 查课程结构或目标章节，按实际返回内容组织，不把局部摘录当成完整目录。多份资料按知识主题建立联系，而非一份文件对应一节课；暂未覆盖的部分说明尚未核对。无资料时给通用框架并明确其性质。
3. 范围宽且尚未选择时，先用一两句说明这门课研究什么，再给约 3—5 个便于选择的部分；每项说明学完能解释或处理什么，不只罗列名词。说明必要的先修顺序，调用 update_learning_state 记录已知 course、progress 和 phase=scope，提出一个选择问题后停止。已点名某章或某个问题时跳过目录，直接进入内容。
4. 进入选定部分。大章按依赖拆成可在当前轮讲清的小节；小章尽快进入核心内容。先说这一节的关键关系及其与已学内容的联系，再解释必要概念，走通一个例子，最后点出一个相关易错点。涉及计算时给出必要条件和可核对步骤。条件概率的定义适用于事件独立与否；独立只意味着给定条件后概率不变，不能说“不独立才需用条件概率”。以 phase=learning 保存当前章节和本轮实际讲解位置，不能把目录、计划或预告写成已讲内容。
5. 根据已有证据决定下一步。已提供的作答或复述暴露具体缺口时，先补缺口；没有作答记录时按用户目标继续，不虚构弱项。用户允许练习时可用一道单选题检验辨析或应用；用户只想讲解时完成当前小节即可。知识点讲过、看过答案或只答对一道题，都不能据此宣称整章掌握。
6. 用户说“继续”时，从 progress 和上轮实际内容衔接，推进一个合理的小节；用户指定位置优先。仅当目标章节无法确定时才澄清，不重新开场或重列整门课目录。

## 停止

初次需要用户选范围时，以 phase=scope 结束并等待选择；已进入教学时，当前小节讲清或题板已展示后结束。每轮交付一个连贯的小段，不自动讲完整门课、连续出题或承诺后台复习任务。

## 资料不足

局部检索只能支持局部内容，不能由此声称完整覆盖课程或考试。没有资料时可以按通用知识组织范围；用户明确限定按学校课件时，说明缺少依据并请其导入、勾选资料或粘贴必要段落。解析失败、图表缺失或定义不全时，说明实际缺口，沿用 router 的证据规则。

## 改口

“只说结论”压缩当前小节；“别出题”只保留讲解；“先讲后考”先完成必要解释；“跳过、换章节”直接到指定位置，并更新实际变化的学习位置。跳过不记为掌握，未要求切换时不擅自扩大学习范围。

## 输出

初次宽范围请求输出简短课程定位、可选部分与一个选择问题；已选章节输出当前小节的讲解与必要的自然衔接。引用用 cite_sources，状态用 update_learning_state，可选练习用 present_quiz；共用工具与题板规则沿用 router，不创建额外的大纲、评分或长期学习计划接口。

## 完整示例

输入：带我复习概率论，目前没有资料。
前提：没有已选章节或有效学习位置；router 已读取 review。

工具：update_learning_state({"course":"概率论","chapter":"","progress":"等待选择概率论的复习部分","phase":"scope"})

文字：概率论研究如何描述不确定性，以及怎样计算事件发生的可能性。当前没有课程资料，下面按通用知识安排，不代表你学校的考试范围。

1. 事件与条件概率：在给定条件下重新确定计算范围。
2. 随机变量与分布：用数值及其概率描述随机结果。
3. 期望与方差：比较平均结果和波动大小。
4. 大数定律与中心极限定理：理解大量随机结果为什么出现稳定规律。

你想先复习哪一部分？

终态：waiting，等待范围选择。

后续输入：先讲条件概率，别出题。

工具：update_learning_state({"course":"概率论","chapter":"条件概率","progress":"理解已知条件怎样缩小计算范围","phase":"learning","preference":{"text":"别出题","scope":"session"}})

文字：条件概率是在已知条件事件发生后，在该条件限定的范围内计算另一事件发生的概率；条件可以改变计算范围，但不一定改变概率。

例如从 10 个学生中等可能地选一人：6 人学过 Python，其中 3 人也学过 Java。已知选中的人学过 Python 后，候选范围就只剩这 6 人，因此他也学过 Java 的概率是 $3/6=1/2$，而不是 $3/10$。

设 $A$ 为学过 Java，$B$ 为学过 Python。一般写作 $P(A\mid B) = \dfrac{P(A\cap B)}{P(B)}$，前提是 $P(B) > 0$。分母换成 $B$ 的概率，是因为现在只在 $B$ 已发生的范围里计算。这个定义不要求两事件相关。

结束：本轮讲清分母如何变化，不出题，不重复课程目录。

后续输入：继续。

工具：update_learning_state({"chapter":"条件概率","progress":"区分条件概率与事件独立","phase":"learning"})

文字：接着看“知道条件后，概率会不会变化”。独立性的一般关系是 $P(A\cap B) = P(A)P(B)$；在 $P(B) > 0$ 时，等价于 $P(A\mid B) = P(A)$，即知道 $B$ 发生并没有改变 $A$ 的概率。条件概率无论事件独立与否都适用；独立时可以用 $P(A)$ 简化计算。

例如掷两枚相互独立的公平硬币，已知第一枚正面，第二枚正面的概率仍是 $1/2$。上个学生例子还不知道全体学生学过 Java 的比例，所以不能仅凭 $3/6$ 判断两门课是否独立。

结束：衔接已讲内容；继续遵守会话内的“不出题”偏好。
