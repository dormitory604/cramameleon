# review · 系统复习
适用：用户要求复习或系统学习一门课、一章或主题。
不适用：单个简单问题、直接索要答案、明确要求考试。
步骤：优先当前选中资料，按需 search_context；先用一两句说清课程要解决什么，再给少量可选部分，等待用户选择；已选部分就直接进入内容。大章按依赖拆分，小章尽快讲，不连续多轮只给目录。
进度：用 update_learning_state 保存课程、章节、当前位置；初次列范围后 phase=scope（等待用户选），进入讲解为 learning。用户切章立刻更新，不默认从第一章开始。
停止：初次范围选择或当前一小段讲清后结束，等待下一条用户动作。不要自动一次讲完整课程。
资料不足：明确当前远程检索不可用；可以根据通用知识给框架，但不假称学校考试范围；资料为空/解析失败时请换资料或粘贴必要段落。
改口：“只说结论”收短当前内容，“别出题”取消练习，“跳过/换章节”进入明确指定部分。
输出：文字说明范围和讲解；引用用 cite_sources；必要练习用 present_quiz，不强制每段出题。
完整示例：
输入：带我复习概率论。当前未选资料。
工具：update_learning_state({"course":"概率论","chapter":"","progress":"选择复习部分","phase":"scope"})
文字：概率论研究如何描述和计算不确定性。目前没有课程资料，下面按通用知识安排，不代表你学校的考试范围。可以从这几部分选一项：1. 事件与条件概率；2. 随机变量及分布；3. 期望和方差；4. 大数定律与中心极限定理。你想先复习哪一部分？
终态：waiting。
后续输入：先讲条件概率。
工具：update_learning_state({"course":"概率论","chapter":"条件概率","progress":"理解条件概率的分母如何变化","phase":"learning"})
文字：条件概率是在已知某件事发生后，重新计算另一件事发生的概率。关键是样本范围缩小了。例如 10 个学生中 6 人学过 Python，其中 3 人也学过 Java；已知某人学过 Python 时，他也学过 Java 的概率是 3/6，而不是 3/10。
