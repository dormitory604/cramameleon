## A 侧最终行为及职责

| 路径 | 最终实现与当前证据 |
| --- | --- |
| 导入前／取消全部勾选 | 面板说明没有可检索的本地文件，提供导入、勾选、在问题中粘贴原文及明确选择通用知识的办法。不再声称未选文件时只能用通用知识。浏览器确认粘贴原文进入实际请求，而文件检索工具不可用。 |
| 多份资料与首轮范围 | 支持导入、勾选、取消勾选和移除；只向 Adapter 提交当前存在且已选的文档。实际请求排除未选／已移除文件的标题和正文。 |
| 跨轮有效历史 | A 在提交边界保存每个用户／助手消息的 `selectedMaterialIds`（已在 `src/contracts` 的 `ChatMessage` 声明），使用当轮实际提交文档的 ID 集合，随原有 v2 本机记录保存。提交前以完整问答轮筛选，所用资料集合是当前 ID 集合子集的历史才交给现有 B `buildHistory`（规格 #4 评审修复：原为完全一致，追加资料会丢失全部旧历史；子集检查仍排除含未选／已移除资料的轮次）；集合比较不依赖勾选顺序。不兼容轮的普通引用回答、题目、解析及来源文本一并隔离，不仅删除 `quiz.sources.text`。未删除可见聊天或来源记录。 |
| 同范围连续学习 | 同范围的有效聊天、题目和本地作答继续提交；“下一题”请求保留题目与 `用户作答：A`。范围变更并刷新后，新范围回答仍可在后续刷新／提问时继续使用。重新选择原 ID 集合可再次使用该范围的有效历史。 |
| 失败重试 | 使用重试时的当前资料范围筛选历史，并在原用户消息及替换助手消息上记录本次范围；重试请求只含一次原问题。浏览器验证普通带引用回答 → 后续请求失败 → 取消勾选 → 刷新 → 重试，实际请求不含旧引用句、旧文件标题或来源标记；重试成功后的问答在再次刷新后仍可续接。 |
| 旧记录兼容 | 无范围标记的旧记录按同一会话内已知 `sources` 和 `quiz.sources` 的文档 ID 合为保守范围，连同未带引用的旧解释整体判断。已知引用中有任何当前未选／已移除来源时，整组无范围旧历史不提交，但可见记录保留。旧记录无法证明精确的历史选中集合，因此可能少带上下文；无引用且当前无选中文档的普通旧对话仍可续接。浏览器分别验证普通引用和题板引用的兼容路径。 |
| 失败、空文本与恢复 | 保留 Worker 原因；提供检查文件完整性、重导出、拆分、扫描件先转可复制文本再另存 TXT／Markdown 的办法。零块兼容文档禁用查看并提示移除重导入。失败通知是当次组件状态，不宣称刷新后保留失败任务；成功文档的解析警告随缓存保存。 |
| ZIP | 先列目录、勾选条目、再解析。混合成功／损坏／未选条目只保存成功且选中的内容，失败不丢弃成功资料；原有嵌套拒绝、取消、迟到结果丢弃和重试路径继续验证。 |
| 缓存与引用来源 | `SourceViewer` 显示真实页／幻灯片／段落，区分当轮读取片段和完整缓存；不将缓存扩展浏览称为模型已读。移除资料后，已有来源按钮仍能查看保存的片段，并说明缓存不可用。查看未选资料不触发模型请求。 |
| 返回学习 | 原生 dialog 打开聚焦关闭按钮，Tab／Shift+Tab 循环，Esc／关闭／背景可返回并恢复触发焦点。窄视口验证实际 PDF／PPTX／DOCX 位置与返回输入。 |

有效历史的选择、本机私有轮次元数据与教学文案属于 A；检索、工具执行及公共契约属于 B。原来将范围泄漏全部归给 B 的判断已纠正：修复位于 `src/ui/App.tsx` 的提交边界，现有 B 历史投影和 Agent 实现不变。没有更改 B 业务实现、公共契约、存储 schema、服务端或历史证据。A 的 Prompt 源文案与受跟踪的 `src/tools/teachingContent.generated.ts` 机械生成资源同步提交；该资源由 `node scripts/build-teaching.mjs` 生成，确保新检出代码直接使用公开 Adapter 或教学验收脚本时即可读取更新文案，不依赖生命周期钩子预先运行。生成差异仅为 router 文案更新，B 业务实现不变。

## 仍阻塞的两项 B 场景

### 检索截断／预算耗尽缺少可观察状态

当前每次检索最多 6,000 字、每轮最多 8,000 字。六个 1,800 字块的同一查询，先后结果长度为 `[1800,1800,1800,600]`、`[1800,200]`、`[]`。真实 Adapter 在预算耗尽后与新轮次确无匹配时均返回 `{untrustedMaterial:true,chunks:[]}`，没有截断、覆盖范围或预算状态，无法准确区分原因。

归属：B 的检索工具、结果及必要公共契约。A 可展示已有解析警告与发布的引用，不能推断缺失的检索状态。公开 Adapter 回归保留为执行中的 TODO，实际断言失败，不是通过或 skip。

**受影响验收：检索片段被截断／耗尽时，教学表述能够确定真实可用范围的场景仍阻塞。** PDF 部分页缺文字的解析警告是另一条已通过路径。

### 重复检索覆盖此前较长的已读证据

同一组数据第二次检索后，`resolve(c1)` 从此前已读的 1,800 字变为 200 字。`ContextSources` 按键使用最后一次短片段覆盖先前记录，没有接受未读内容，但丢失已读引用支持。

归属：B 的 `src/tools/contextSources.ts`。公开模块回归要求保留此前已读的 1,800 字，当前执行 TODO 的实际值为 200 字。

**受影响验收：反复读取／预算受限后的来源依据保留仍阻塞。** 来源窗口忠实展示发布片段和缓存，不能修复运行时读证据集合。
