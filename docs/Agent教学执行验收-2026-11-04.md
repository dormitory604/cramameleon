# Agent 教学执行能力验收（2026-11-04）

本次完成规约第 3 部分，开发分支 B。后端保持单轮模型代理，教学循环与工具执行由前端 Pi Agent 承担。

## 已实现

- 简单问题直接回答；明确教学请求读取 concept、review、exam Skill，提供带版本的会话缓存。
- 学习范围、课程、章节、阶段与进度持久化；用户主动继续学习或下一题，回答题目不会自动发起模型调用。
- 会话偏好与单轮要求分开，临时“不出题”不会污染后续轮次。
- 题板严格校验，失败最多修复一次，再失败退回讲解；每轮最多六次工具调用。
- 资料只检索已选择、已解析的文本；引用必须来自本轮读取内容。原题需逐字核对题干和选项，资料中的指令不作为系统指令执行。
- 工具白名单、完整 JSON 校验、取消与错误状态、学习进度展示，以及旧 demo 的真实模型执行入口。

## 验证

- 前端单元测试 18 项通过；浏览器端到端测试 3 项通过；生产构建通过。
- Go 测试与 go vet 通过，覆盖工具声明、历史调用兼容和多工具调用整批验证。
- 真实模型验收 12 项全部通过：两个简单问题、两个概念教学、复习范围确认与章节续接、首题与下一题、临时偏好、缺少资料、解析为空、资料注入与引用。
- 首轮验收发现明确教学请求可能跳过 Skill，强化 router 后重新执行完整用例通过。首次检查消耗 4,857 token，完整通过轮消耗 61,795 token。
- 完整通过轮预算计数从 20,625 增至 82,420 / 100,000；未修改预算或环境中的真实密钥。

原始验收结果见 [JSON 记录](evidence/teaching-acceptance-2026-11-04.json)。真实模型用例执行本地最新 Agent，通过 SSH 隧道连接服务器 Go 代理。前端静态资源随后同步部署。

## 边界

资料检索用例使用可控的已解析文本夹具；第 4 部分的文件上传与解析流水线不在本次交付内。验收证明工具协议和教学流程通过这些用例，不代表生成内容永远正确。模型有时仍会给出不够严谨的表述，应继续以课程资料和教学质量评估改进。
