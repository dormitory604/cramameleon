# 旧站身份与课程资料接入

旧站账号授权、资料搜索与目录、确认读取和浏览器解析已接入。旧站和本应用各自运行后端，通过固定集成 API 通信；当前运行方式见 [README](../README.md)，历史联调记录见 [文档目录](README.md)。

## 使用方式

旧站导航「AI复习」进入学习助手介绍页。资料页的「用 Cramameleon 复习」直接发起 Cramameleon 登录流程，自动沿用当前破壁计划账号。未登录或登录失效时，完成破壁计划登录后继续。正式模式为 APP_ENV=old-site，所有破壁计划账号均可使用。

从资料页进入时自动导入支持的单份资料或课程包文件。预览包内文件时导入该文件。课程包超出当前对话容量时打开目录供选择。在输入框「添加」中也可搜索课程资料、浏览目录并确认读取。

已导入、解析并勾选的旧站资料与本地文件共用 search_context、read_context 和 cite_sources。查询“第一题”或“开头”时可顺序阅读缓存，不依赖关键词匹配。Agent 不会搜索远程目录、自动下载或扣额；目录标题不能当作正文依据。

## 服务配置

OLD_SITE_CLIENT_ID 与 OLD_SITE_CLIENT_SECRET 在两个后端对齐，使用独立集成秘密，不复用旧站 JWT 密钥。

APP_CREDENTIAL_KEY 是独立的 32 字节加密密钥，配置为 64 位十六进制。环境文件和数据库保留在服务器私有目录，不提交仓库；示例文件不代表服务器当前额度或路径。

## 下载权益

- 搜索和目录免费，读取文件由用户明确确认。具体额度、周期结束时间和回执状态以旧站返回为准。
- 首次读取按旧站规则扣次，已有历史下载或有效读取授权可复用。课程包按授权读取支持的条目，不逐份扣次，不自动下载整个 ZIP。
- 读取请求编号绑定用户；网络中断后复用同一编号，避免重复扣额。请求过期或冲突时提示重新确认，不能静默新建下载。
- 确认后取消或解析失败，已扣额度不自动退回；授权有效时可重试字节读取。本机已有解析缓存的文件直接复用。
- 旧站下载次数、应用模型 token 预算、本轮缓存文本读取预算分别计算，不能混用提示。

## 权限与边界

授权使用单次短时 code、浏览器绑定 state、S256 PKCE、固定回调和后端客户端认证。应用会话有效 8 小时；旧站受限凭据加密保留在后端，不交给浏览器。凭据失效会停止远程读取，但有效应用会话内的本地或缓存文本仍可使用。

适配器只请求固定旧站 origin 的白名单接口，不接受任意 URL，不跟随重定向，不读取旧站数据库或存储目录。资料请求带当前应用用户标识，业务 POST 校验固定 Origin；账号切换会取消旧任务、清空旧视图，记录按用户隔离。

支持 TXT、Markdown、文本 PDF、DOCX、PPTX，单份最多 20 MiB，每对话最多 20 份。课程包只选择并读取支持的条目；扫描件不做 OCR，图表、公式对象和复杂布局受现有解析能力限制。完整文件和缓存限制见 [README](../README.md)。

## 验证与运维

server/auth_test.go、materials_test.go 覆盖入口、PKCE、会话身份、资料页自动导入、资料凭据、固定上游和读取边界。tests/e2e/entry.spec.ts、old-site-materials.spec.ts、material-scope.spec.ts 覆盖旧站界面、确认读取、重试、Worker 解析、缓存复用、Agent 正文阅读与用户隔离；可控响应回归不登录生产账号、不扣真实下载次数。

发布使用 main 工作流和 PM2 发布锁。发布前备份程序、启动配置与数据库；回滚程序时保留当前数据库，不能用旧备份覆盖新产生的下载权益和模型记账。使用私有回调配置并避免日志记录授权码；正式 Cookie 使用 Secure、HttpOnly、SameSite=Lax。

真实模型教学验收见 [验收说明](../scripts/acceptance/README.md)，它复用正常授权取得的应用会话，不提供绕过旧站入口的测试登录。
