# 旧站身份与课程资料接入

本次以 mini 的完整运行源码为旧站基线，已重现原 Linux 二进制及前端资产哈希，再统一 mini 和 zzs 的提交。新站保留当前线上 main 的界面、Markdown、学习记录恢复和模型预算实现，合入旧站授权与资料适配。

## 使用方式

旧站导航“AI 学习”进入 `/cramameleon`；单份资料及课程包详情也有“用 Cramameleon 复习”入口。使用原账号登录，在旧站确认授权后进入新站。新站生产模式为 `APP_ENV=old-site`，统一内部口令接口不存在，访客配置不能绕过此模式。

在输入框“添加”中选择“搜索课程资料”，搜索单份资料或课程包，查看分页目录、选择文件、确认读取。携带资料入口进入时只自动打开目录，不自动下载或扣额。文件经旧站授权 API 与新站固定适配器读取，在浏览器 Worker 中解析；不向模型开放自动扣额下载工具。

## 内测名单

由新站服务器私有 `.env.old-site` 中 `APP_ALLOWED_OLD_USER_IDS` 控制，填写逗号分隔的旧站数字 ID。首批为 `922`（用户指定的 xushh55@mail2.sysu.edu.cn）。修改名单并重启 Cramameleon 后生效；每个请求都会重新核对名单，移除的账号不能继续使用已有应用会话。新增账号以旧站查询确认 ID，不能用昵称或前端传来的邮箱作为身份。

名单未提供网页管理界面。私有文件权限为 0600，不提交仓库。独立客户端秘密用于两端后端通信，另设 32 字节密钥加密新站保存的受限凭据；不复制旧站 JWT 密钥到新站。

## 下载权益

- 搜索和目录免费。沿用旧站“首次历史下载才扣一次”的规则，历史下载过的资源重读不再扣额度。
- 课程包首次读取扣一次；本周期内的包授权覆盖其支持的文件，逐份读取不重复计次。包授权到用户当前七天周期结束；周期按旧站注册日期的 UTC 零点计算，非自然周。
- 普通资料读取授权有效 30 分钟。创建新授权沿用旧站每日每资源十次的规则，首次下载也计入当天次数。普通下载与新授权共用同一个 SQLite 立即事务，原子处理额度、历史记录和计数。
- 请求编号按用户绑定并保存回执；同一请求重试返回原授权，不能重复扣额。网络中断后浏览器保留编号供重试。过期请求提示重新确认，不能静默作为新下载。
- 先核对文件存在、格式、大小和条目所属，再授权扣额。确认后取消或解析失败，已扣额度不自动退回。授权有效时可重试字节读取。

## 权限与边界

授权使用单次短时 code、浏览器绑定 state、S256 PKCE、固定回调和后端客户端认证。受限凭据哈希存于旧站，加密存于新站，不交给浏览器；八小时到期，可撤销。新站会话与旧站资料授权状态分别处理。

新站适配器只请求固定旧站 origin 的接口，不接受任意 URL，不跟随重定向，不读取旧站数据库或存储目录。GET 和 POST 资料请求均校验当前用户头；业务 POST 另验固定 Origin。换账号会取消旧任务并清空旧视图，本机资料和记录按真实用户隔离。

旧站只读取数据库选中的、位于自身数据目录内的普通文件。课程包仅按条目 ID 读取，不解包落盘；限制 ZIP 目录大小、条目数量和选中文件大小，拒绝越界、重复条目、符号链接和加密条目。支持 TXT、Markdown、文本 PDF、DOCX、PPTX，单份 20 MiB，每次最多 20 份。扫描件和复杂版式仍受现有本地解析能力限制。

## 验证与发布

Go 测试覆盖单次授权、PKCE、用户隔离、额度并发、历史权益、回执重试、授权过期、撤销、固定上游与文件目录边界。真实双后端浏览器夹具完成旧站登录态 → 授权 → 新站实名会话 → 目录选择 → 扣一次额度 → 浏览器 Worker 解析 → 查看来源，并验证未获邀账号被拒。夹具使用独立数据库、测试密钥和测试文件，未登录生产账号或消耗其额度。

旧站入口已检查 1280、768、390 像素；新站手机目录和来源也已检查。合并后执行原学习、资料、记录、恢复、键盘和手机回归。两项已有的 TODO 单元用例仍记录检索证据预算限制，本次没有改动检索算法。

发布前备份 SQLite、旧二进制、前端和启动配置。旧站继续保留原 JWT 配置，启动加载私有 SMTP 与集成配置。新站沿用 main 自动发布机制及发布锁。回调访问日志关闭以免记录授权码；Cookie 使用 Secure、HttpOnly、SameSite=Lax。回滚使用旧程序与配置，保留当前数据库的下载和模型记账，不能用旧备份覆盖新产生的额度记录。
