# 旧站资料内容读取修复

> 历史验收记录：本文仅反映当时的实现、命令与验证结果，不代表当前功能或部署状态。现行说明见 [项目 README](../README.md) 和 [文档目录](README.md)。

## 原因

旧站资料的授权下载、浏览器解析及已选资料传入 Agent 的链路可用。截图中的资料为旧站 material `5232`，实际 PDF 大小 313856 字节；用浏览器 Worker 验证可以提取 2 个文本块，第一页包含“设 A、B 为两个随机事件，且 B ⊂ A”的第一道选择题。

Agent 层存在两个缺口：

- 发布的系统提示仍写着“旧站授权尚未接入”，与实际已选资料相矛盾，也容易沿用先前“没有资料”的回答。
- 原先只有关键词检索。问“第一题”时，这几个字未必出现在试卷正文，无法通过关键词稳定定位资料开头；Agent 缺少直接阅读已选缓存的工具。

## 改动

- 更新路由及教学提示，明确旧站资料经用户确认读取、解析和勾选后，与本地文件一样可读；当前已选范围优先于历史中的无资料状态。
- 元数据增加来源、格式和文本块数量。新增 `read_context`，按 documentId 和从 1 开始的文本块序号顺序阅读，每次最多 3 块；返回续读位置、截断和预算耗尽状态。
- 顺序阅读与检索共享每轮 8000 字证据预算，不访问网络、自动下载或扣旧站额度。取消勾选的资料不进入当前工具范围，来源仍只能引用本轮实际读到的文本块。
- 重复读取不会用更短的片段覆盖已经读过的较长证据；对应已有 TODO 回归已转为正常测试。
- 前后端工具白名单同时加入 `read_context`，保持 `app.v1` 和既有会话、数据库格式。

## 验证

- 先增加旧站导入后发送问题的回归，确认原实现可以取回内容，但模型请求中仍包含错误的“旧站未接入”声明；该回归在修复前失败。
- 增加无关键词顺序阅读、来源身份、引用、读取预算、续读位置及未选资料隔离的单元验证。
- 浏览器回归覆盖旧站单份 PDF 与课程包导入、真实 Worker 解析、Agent 阅读第一页并引用、刷新后缓存复用、旧无资料历史、取消勾选后的隔离。验证阅读与复读不会新增下载授权或文件请求。
- 截图对应的真实 PDF 另以本机诊断副本通过浏览器 Worker 解析验证，未登录生产账号或扣其下载额度；该文件不提交仓库。
- 全部 Go 测试、`go vet ./...`、前端构建通过；模块测试 49 通过、1 个已有 TODO。开发和生产构建的浏览器回归各 25 项通过。

剩余 TODO 是关键词检索预算耗尽与没有匹配文本的返回状态区分；本次新增的顺序阅读已提供明确的预算状态。
